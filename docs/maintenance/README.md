# 유지보수 · 학습 문서

이 폴더의 문서는 **구현된 코드와 연결된 유지보수 자료**입니다.
일반적인 Delphi 문법 정리가 아니라, 실제 이 프로젝트의 코드를 읽고
고치기 위한 안내서입니다.

문제가 생기거나 기능을 확장할 때 다음 순서로 사용합니다.

1. 해당 모듈 문서를 읽는다.
2. 코드가 어떤 흐름으로 동작하는지 파악한다.
3. 필요한 Delphi 지식을 확인한다.
4. 수정해야 할 파일과 위치를 찾는다.
5. 유지보수 또는 기능 확장을 진행한다.

## 구성

- [architecture.md](architecture.md) — 전체 구조와 데이터 접근 방식 개요
- 모듈별 문서 — 각 모듈 구현 완료 시 [`_template.md`](_template.md) 형식으로 추가

## 문서 작성 원칙

각 모듈 문서는 아래 항목을 담습니다.

1. 구현한 기능
2. 관련 파일과 주요 클래스·메서드
3. 코드 실행 흐름
4. 데이터가 생성·변경되는 위치
5. 이해에 필요한 Delphi 학습 항목
6. 수정·확장 시 확인할 위치
