# src

소스 트리입니다.

- `core/` — 공통 계약. 데이터 접근 인터페이스(`IItemRepository` 등)와
  엔티티(레코드/클래스), Memory·Firebird 두 프로바이더가 여기에 위치합니다.
  모든 모듈이 의존하는 토대이므로 인터페이스는 안정적으로 유지합니다.
- `modules/` — 모듈별 유닛. 모듈 하나당 하위 폴더 하나
  (`item/`, `partner/`, `inventory/`, `quote/`, `shipment/`, `history/`).
- `app/` — 메인 셸. 애플리케이션 진입점, 메인 폼, 프로바이더 초기화/선택.

## 식별자·주석 규칙

- 클래스·변수·메서드 등 **식별자는 영어**.
- **주석과 화면 라벨(UI 텍스트)은 한글**.
